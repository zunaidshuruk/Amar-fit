## ✅ PART Y — AI RESPONSE OVERHAUL (complete)

Zunaid's request: AI chat answers looked scattered — make them more structured, more beautiful and easier to understand. Diagnosis: (1) `MarkdownText` drew everything except tables/video buttons as one flat block (no spacing, no hanging-indent bullets, no numbered steps, no callouts); (2) chat bubbles were plain grey boxes with no identity or actions; (3) each prompt had its own loose formatting rule, so answer shape varied.

1. [x] **Renderer** — `f8deaa3`, `ui/components/MarkdownText.kt` only. Blocks: Heading (accent bar, spacing), Paragraph, Bullets (hanging indent, nested), Numbered (accent badges), Callout (`> **Label:** text` → labelled accent card), plus inline `**bold**`, `*italic*`, `` `code` ``. Tables → cards, `---` → divider and `YOUTUBE_SEARCH:` → red Watch button unchanged. Accent washes use `primary.copy(alpha=…)` so it works on any background. Also restyles the Legal screens. Known edge: `*a **b** c*` can mis-pair italics (cosmetic).
2. [x] **Answer style guide** — `7895480`, `AppRepository.kt`: `aiResponseStyle(maxWords, followUps = false)` appended to six conversational prompts (`getChatResponseStream`, `getChatResponse`, `generateCoachAdviceStream`, `generateCoachAdvice`, assistant main + fallback). Shape: one-line answer first; up to 3 `##` sections; ≤4 bold-led bullets; numbered only for ordered steps; one `> **Next step:**` line; plain language, local foods/units, the user's own numbers; no tables/emojis in chat; ~150 words (coach ~250). JSON prompts and insight prompts are untouched.
3. [x] **Message card** — `dfd1681` (new `ui/components/AiMessageCard.kt` + Assistant) and `efae5c8` (live Chat, saved-chat viewer, Food Chat): full-width card on `surface` with a faint outline, "KardIQ AI" header with accent logo, copy button (copies text without `YOUTUBE_SEARCH:`/`FOLLOWUPS:` lines; icon turns into a check for 1.5 s). The Coach advice dialog deliberately does not use the card (it is a dialog, not a chat bubble).
4. [x] **Follow-up chips** — `166f38c`: chat/assistant prompts (`followUps = true`) ask for one last line `FOLLOWUPS: q1 | q2`; `AiMessageCard` hides it everywhere and shows up to 3 outlined chips only under the newest answer, after loading finishes, in the Assistant and the live Chat. Tapping a chip sends the question. Edge: live Chat cuts everything after a `YOUTUBE_SEARCH:` line, so recipe answers there show no chips (harmless).

Conventions to keep: `YOUTUBE_SEARCH: <dish>` and `FOLLOWUPS: q1 | q2` must each be on their own line, never inside a table; the renderer and card depend on that.
