## ✅ PART I — DETAILED HEART RATE SCREEN (Google Health parity) — 6/7 of original scope done, plus the full cosmetic redesign (8) now complete

Triggered by comparing against Google Health's Heart Rate detail screen: intraday chart with zone-boundary reference lines, "Time in heart rate zones" percentage/minutes breakdown, a trend/zones sub-tab toggle, weekly-bucketed rows on Month/3M views, delta callout text, medical disclaimer.

**Feasibility finding:** `ShasthoViewModel`'s existing sync code already calls `healthConnectClient.readRecords(ReadRecordsRequest(HeartRateRecord::class, ...))` and gets full timestamped samples back — it just discards everything except `samples.last().beatsPerMinute`. So the intraday data source already exists; no new Room table needed, Health Connect can be queried live per historical date. Zone thresholds derived from the standard formula (max HR = 220 − age; Peak 85-100%, Vigorous 70-84%, Moderate 50-69%, Light <50%).
